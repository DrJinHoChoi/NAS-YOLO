\section{Per-Class BSI Analysis}
\label{sec:supp_perclass}

We report per-class BSI for representative COCO categories. Larger objects (car, bus) exhibit higher baseline BSI, but NAS-YOLO provides consistent improvements across all sizes. Small objects (bottle, cup) benefit most from temporal state, as their detection is most susceptible to noise-induced false positives and localization jitter.

\section{Noise Estimator Analysis}
\label{sec:supp_noise}

The spectral noise estimator analyzes the DCT frequency spectrum of the input image. We visualize the learned noise descriptors for different corruption types and severities using t-SNE projection. The descriptors form distinct clusters by corruption type, confirming that the estimator captures meaningful noise characteristics rather than overfitting to specific corruption patterns.

\section{Failure Cases}
\label{sec:supp_failure}

NAS-YOLO's temporal state can be counterproductive in specific scenarios:
\begin{enumerate}
  \item \textbf{Rapid ego-motion}: When the camera undergoes fast translation or rotation, the temporal state from previous frames becomes misaligned with the current view, temporarily degrading detection until the scene-change detector resets the state.
  \item \textbf{Fast-moving objects}: Objects that traverse a significant portion of the frame between consecutive time steps are poorly served by temporal smoothing, as the S3M state encodes the previous position.
  \item \textbf{Corruption-free video}: On perfectly clean video, the NAS module adds negligible overhead ($<$1ms) but provides no benefit, as the gate correctly passes features through unmodified.
\end{enumerate}

These cases are inherent to temporal methods and could be addressed by adaptive state management with motion compensation, which we leave for future work.
